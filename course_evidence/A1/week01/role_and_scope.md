# A1 role and scope

This retrospective records the Week 1 scope of the A1 responsibility in the repository as it stood during the Week 4 catch-up. A1 owns plugin metadata (`metadata.yaml`), configuration schema (`_conf_schema.json`), Python package metadata (`pyproject.toml`), and only the configuration-reading, Node.js setup, and JavaScript dependency-preparation regions of `main.py`.

The role's Week 1 goal is to keep those declarations and startup paths understandable and verifiable. This file was created during Week 4; it does not claim an earlier meeting, implementation, or test run.
