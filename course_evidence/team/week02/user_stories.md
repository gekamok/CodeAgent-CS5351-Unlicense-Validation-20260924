# User Stories

These are product goals recorded retrospectively during Week 4; they are not claims of completed interviews.

- As an AstrBot operator, I want plugin settings described by a schema so I can configure the coding workflow consistently.
- As a chat user, I want to request a coding task through the plugin so the workflow can act on a project.
- As a project maintainer, I want execution, packaging, and security behavior to be reviewable so changes can be checked before delivery.
